TAKE 01 // SIN #01 // INGREDIENTS MODE FREEZE

Take 01: The 6-Second PNG & Turn-Signal Metronome

> MATTHEW: "I'm confused, was it supposed to do something? *ding!* Oh, yeah, but I didn't do first frame last frame. That was just set to ingredient."

Chalk up a classic 50/50 studio lab own-goal. Feeding a finished hero plate into Flow's Ingredients mode instead of Frames -> Start while stacking phrases like "locked dead-steady" and "completely rigid" told the diffusion solver to treat the hero plate as an immovable poster. Meanwhile, requesting "electric ticker relay click" dutifully laid a loud mechanical left-turn blinker over six seconds of pure stasis.

// BLUE TEAM DIAGNOSIS & TWO-CLICK FIX
  • Mode Trap: Flip the composer dropdown from Ingredients to Frames -> Start ONLY (leaving the End Frame empty so Omni cannot cheat with a zero-velocity identity shortcut).
  • Audio Hygiene: Delete "electric ticker relay click" permanently so the sound engine stops clocking a car turn signal.
